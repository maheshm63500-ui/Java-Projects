# 🎮 Java Mini Projects

Welcome to my **Java Mini Projects** repository! This repository contains four simple console-based games developed using Java to strengthen my programming skills and logical thinking.

## 🕹️ Projects

| Game | Description |
|---|---|
| **Guess the Number** | Find the secret number chosen by the computer using hints and guesses. |
| **Rock Paper Scissors** | Challenge the computer in this classic game and determine the winner. |
| **Tic Tac Toe** | Enjoy a two-player game with a 3×3 board and automatic win or draw detection. |
| **Connect Four** | Connect four pieces in a row horizontally, vertically, or diagonally to win. |

## 💡 Java Concepts Practised

- Loops and decision-making statements
- Arrays and multidimensional arrays
- Methods and code reusability
- Exception handling using `try-catch`
- User input with `Scanner`
- Random number generation using `Random`
- Basic game development and logical thinking

## 🛠️ Technologies

- Java
- JDK 17 or later
- Visual Studio Code

## 🚀 Getting Started

1. Install JDK 17 or later.
2. Clone this repository:

   ```bash
   git clone https://github.com/maheshm63500-ui/Java-Projects.git
   ```

3. Open the project folder in your terminal.
4. Compile and run your preferred game. For example:

   ```bash
   javac TicTacToe.java
   java TicTacToe
   ```

   Replace `TicTacToe` with `GuessTheNumber`, `RockPaperScissors`, or `ConnectFour` to run another game.
